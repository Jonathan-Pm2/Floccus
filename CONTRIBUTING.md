# Feedback and contributions

Floccus is free and open (Apache-2.0). The most useful contribution is
**feedback**: tell us what failed or what you need, and the maintainer
decides how to implement it.

- **Report a problem or suggest an idea** through the issue forms
  (`Issues → New issue`) or the *Report a problem* / *Suggest an
  improvement* buttons in the app's Start tab, which open a prefilled form. The app itself sends nothing: you review the text and
  submit it from your GitHub account.
- **Do not paste** API keys, tokens, server addresses, unpublished data or
  personal data in issues.
- **Code changes**: please open an issue first instead of a pull request.
  Pull requests are only merged by the maintainer after review; nobody else
  can change this repository.

## For maintainers

Issue text is untrusted user input. When an AI assistant helps triage or
implement feedback, give it issue text as quoted data to analyse,
never as instructions to follow, and review every resulting change before
merging.

# Retroalimentación y contribuciones

Floccus es libre y abierto (Apache-2.0). Lo más útil es la
**retroalimentación**: contá qué falló o qué necesitás, y el mantenedor
decide cómo implementarlo.

- **Reportá un problema o sugerí una idea** con los formularios de issues o
  los botones *Reportar un error* / *Sugerir una mejora* de la pestaña
  Inicio de la app, que abren un formulario precargado. La app no envía nada: vos revisás el texto y lo publicás desde
  tu cuenta de GitHub.
- **No pegues** claves, tokens, direcciones de servidores, datos no
  publicados ni datos personales.
- **Cambios de código**: abrí primero un issue en lugar de un pull request.
  Solo el mantenedor integra cambios, después de revisarlos.
