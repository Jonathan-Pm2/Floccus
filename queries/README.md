# Search strings

The per-database search strings used to identify the corpus, transcribed
verbatim from the review protocol. All four core databases were searched in
June 2026 and returned 22,056 records.

| database | file | field / restrictions | records |
|---|---|---|---:|
| Scopus | [`scopus.txt`](scopus.txt) | `TITLE-ABS-KEY` (title, abstract, keywords); `PUBYEAR > 1800 AND PUBYEAR < 2027` (operationally no year limit); `DOCTYPE(ar)` | 6,380 |
| Web of Science | [`web_of_science.txt`](web_of_science.txt) | `TS=` (Topic: title, abstract, keywords); searched across all Web of Science databases, not the Core Collection alone; Document Type = Article through the interface refiner; no year limit | 10,685 |
| IEEE Xplore | [`ieee_xplore.txt`](ieee_xplore.txt) | Command Search on `"All Metadata"`; reduced three-axis version (IEEE Xplore restricts wildcards and long boolean strings) | 545 |
| SciELO | [`scielo.txt`](scielo.txt) | independent term searches in Spanish/Portuguese, replayed with English equivalents; results merged at ingestion | 4,446 |

All strings share one three-axis design: a **modelling** axis (mathematical,
numerical or kinetic model, simulation) AND a **biological-floc** axis
(biofloc, bacterial/microbial floc, activated sludge, periphyton) AND an
**applied-context** axis (aquaculture, wastewater and water treatment, water
quality). The screening criteria then evaluate these axes one at a time.

Records outside the article and review document types that some exports still
contain were evaluated during screening by the deterministic document-type
criterion I4 (`src/biofloc_review/screening/prefilter.py`).

## Supplementary search: ProQuest EAASD

Coverage of aquaculture-specific literature was checked with a supplementary
search, reported separately and not merged into the analysed corpus:

- **database**: ProQuest Earth, Atmospheric & Aquatic Science Database (EAASD);
- **date of search**: 25 October 2026;
- **filter**: peer reviewed;
- **query**: the three-axis query above, extended with the biofloc-technology
  terms `bio-floc*`, `BFT`, `"zero water exchange"` and
  `"minimal water exchange"`;
- **records retrieved**: 950.

The command string as typed into the ProQuest interface was not archived; the
components above are those stated in the manuscript. The analysis is
regenerated by `scripts/supplementary_search_eaasd.py` (requires the ProQuest
export, which cannot be redistributed).

## Enrichment sources

OpenAlex and Europe PMC were used only to enrich records already retrieved
(abstracts, topics, MeSH terms, open-access links). They were not queried
with boolean strings and contributed no records.
